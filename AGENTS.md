# For AI coding agents

If a person asks you to build them their own Takeaway (a tool that turns the videos and links they save on their phone into notes they can review), follow the step-by-step guide in [`skills/build-my-takeaway/SKILL.md`](skills/build-my-takeaway/SKILL.md).

It works with any agent that can run shell commands and edit files: Claude Code, Codex, Cursor, Gemini CLI and others. The processing worker it sets up uses Claude Code, so the person needs Claude Code installed and signed in on their computer.
